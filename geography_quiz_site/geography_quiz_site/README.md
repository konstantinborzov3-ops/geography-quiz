# География — онлайн-тест

Готовый сайт-тест на 20 вопросов по теме «Нефтяная промышленность России и мира».

## Запуск

1. Установите Node.js 18+.
2. Откройте терминал в этой папке.
3. Выполните `npm install`.
4. Выполните `npm start`.
5. Откройте `http://localhost:3000`.

## Куда приходят результаты

По умолчанию каждый результат сохраняется в `results.json` на сервере.

Чтобы получать уведомления в Telegram, скопируйте `.env.example` в `.env` и заполните `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. После этого перезапустите сервер.

Перед размещением сайта в интернете обязательно закройте или защитите `GET /api/results`, потому что сейчас он предназначен для владельца сайта и без авторизации отдаёт сохранённые результаты.

## Что внутри

- Регистрация по имени и фамилии.
- 20 вопросов с вариантами ответа.
- 4 вопроса по материалу на фотографиях + 16 дополнительных вопросов.
- Подсчёт баллов и процента.
- Отправка результата на сервер.
- Сохранение результатов в JSON.
- Опциональное уведомление в Telegram.
